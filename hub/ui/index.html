AÇIK
2. Eşya, Mekan, Stat, Set ve Boon/Condition Terimlerini İngilizce Bırak Wiki aramaları, Trading Post, build rehberleri ve sohbet linkleri (%100 uyum) için eşya, harita, statlar (Power, Toughness), setler (Berserker, Viper) ve boon/condition'ları İngilizce korur.
AÇIK
3. Oyun İçi Çeviri Aç / Kapa Kısayolu (Nexus InputBinds) Oyundayken çeviriyi anlık açıp kapatmak için kullanılan kısayol tuşu (Varsayılan: ALT + T).
4. Çeviri Motoru & Performans (Çevrimdışı Öncelikli) Ana destek çevrimdışı OPUS-MT modelidir. İsteğe bağlı bulut çeviri seçerseniz API anahtarı girebilirsiniz.
5. Çeviri Düzenleyici Profili & String ID Gösterimi (show_keys) Düzenlediğiniz metinlerin kaydedileceği profil adı ve oyun içinde metinlerin başında String ID (44547 - Metin) gösterme modu.
